## MODIFIED Requirements

### Requirement: 会话历史跨重启持久化

系统 SHALL 将每个会话（以 `thread_id` 标识）的完整消息历史持久化到本地磁盘，使其在应用进程退出并重启后仍可完整读回。该持久化由本机运行时 server 的 checkpointer 承担；应用 MUST 为其配置一个**持久化到磁盘**的 checkpointer，MUST NOT 使用仅存于内存、重启即丢的临时存储作为默认会话存储。

#### Scenario: 重启后读回历史

- **WHEN** 用户在某会话中产生若干轮对话，随后关闭并重新启动应用，再次打开该会话
- **THEN** 系统展示该会话此前的全部消息历史，且后续消息在此基础上继续追加

#### Scenario: 默认存储非易失

- **WHEN** 应用以默认配置启动并完成若干会话
- **THEN** 这些会话的历史落盘保存，应用重启后仍可读回，而非因运行时 server 的内存态默认而丢失
